# LinkedIn posts

One file per article, named `<slug>.md`, containing nothing but the post —
no frontmatter, no heading, no commentary.

The Monday editorial job writes one every week. `/api/draft-notify` picks it
up when the review email goes out, so the post arrives already written and
ready to paste rather than sitting here waiting to be remembered.

Anything dropped in here by hand for another article works the same way.
