Cover briefs for the Monday column, one per editorial, written by the Monday
run alongside the article.

Each file is a ready-to-paste prompt: the fixed style from
`notes/editorial-cover-style.md` plus the scene that belongs to that week's
argument. Generate the image with Gianluca's own likeness reference and save it
to `public/img/blog/editorial/<slug>.jpg` at 1200x900.

The article stays a draft until that file exists. Approving early is safe — the
publish check refuses and names the missing file.
